# 🎯 세 줄 요약

1. 색깔말은 RGB 색으로 타입과 능력치가 결정되며, 최대 3마리를 배치해 턴제 전투를 진행한다.  
2. 기술 또는 볼을 사용해 상대에게 피해를 주거나 색을 섞고, 색이 지나치게 밝거나 어두우면 사망한다.  
3. 기술은 20면체 주사위로 명중 여부를 판정하며, 타입 상성과 보정, 대응 시스템이 전략의 핵심이다.

# 🎮 게임 진행 규칙서

## 1. 시작 준비

- **스타팅 타입 선택**: 불 🔥 / 물 💧 / 풀 🌿 중 하나를 선택합니다.
- **색깔말 생성**: 선택한 타입과 노말 타입을 기반으로 총 6개의 색깔말이 생성됩니다.
- **말 배치**:
  - 최대 3마리 선택하여 **스테이지 하단 절반의 격자점**에 배치할 수 있습니다.
  - 드래그로 배치.

---

## 2. 전투 진행

- **전투 시작**: `Start` 버튼을 눌러 시작합니다.
- **턴 제도**:
  - 각 색깔말에게 턴이 돌아옵니다.
  - 자기 턴에는 말이 **살짝 투명**하게 표시됩니다.
- **행동 선택** (턴당 1회 가능):
  - **기술 사용**: 기술 클릭 → 상대 클릭
  - **볼 던지기**: 볼 클릭 → 상대 클릭
    - 마우스 **우클릭**으로 볼 전환 가능
  - **이동**: 이동 가능 거리 소모하여 자유롭게 이동
  - **자동 시전**: 키보드 `P` 또는 `Auto` 버튼으로 무작위 기술 사용
- **턴 종료**: `End` 버튼 또는 `Enter` 키로 종료

---

## 3. 전투 효과 및 진행

- **기술 명중 시**: 상대 HP 감소
- **볼 명중 시**: 볼의 색이 상대에게 **섞임**
  - 색이 너무 **하얘지거나 까매지면 사망**
- **스테이지 규칙**:
  - n스테이지에서는 **n명의 적**이 출현
  - 최대한 많은 스테이지를 돌파하는 것이 목표

# ⚙️ 색깔말 시스템

## 타입 결정

- **RGB 값 기반**으로 타입이 정해짐
- **첫 번째 타입**: RGB공간 내에서 가장 가까운 **타입 점**에 따라 결정  
  (타입 점은 (0, 128, 255) 기준으로 분포)
- **두 번째 타입**: 첫 번째 타입 주변의 **스킬 점**으로 결정  
  (스킬 점은 (0, 64, 128, 192, 255)에 분포)
- **M계열 타입**: 기존 타입에 '2'가 붙은 확장 타입.  
  - 상성은 동일하지만 더 **강력한 스킬**을 가짐.

![image](https://github.com/user-attachments/assets/0c4d94ee-2c65-4499-9e1c-5bd01dbcbaf6)


## 능력치 계산 (RGB → H/A/B/C/D/S)

RGB값 = (R, G, B)  
각각을 16으로 나눈 **나머지** = (r, g, b)

- 체력 H = g  
- 공격 A = r  
- 방어 B = 15 - b  
- 특수공격 C = b  
- 특수방어 D = 15 - r  
- 스피드 S = 15 - g  

**보조 파라미터**
- 최대 HP = 60 + 5 × H  
- 이동 거리 = 8 + (S ÷ 2)  
- 턴 순서는 S가 높을수록 먼저, 같으면 무작위

# 🛠️ 기술 시스템

## 스킬 구조

- 한 색깔말은 **최대 4개의 스킬**
- 스킬 구성: `위력(pow), 명중치(acc), type1, type2, 물리/특수(Phy/Spc), 사거리(range), 부가효과(info)`
- **새로운 색이 되면** 해당 색에 해당하는 스킬을 학습  
  → 4개 초과 시 **가장 오래된 스킬**을 잊음

## 명중 판정

- 20면체 주사위 사용  
- 명중 판정 = 주사위 값 ≥ **명중요구값**
- **명중요구값 계산법**  
  (물리 기술 기준):

```
(100 - acc) ÷ 5 + max(상대 방어 - 내 공격, 0) ÷ 2
```

예시: acc = 90, 상대 방어 = 15, 내 공격 = 0 → 명중요구값 = 2 + 7 = 9 (0.5는 버림)

- 보정 효과:
  - **1**: 항상 빗나감
  - **20**: 항상 명중 + 치명타
  - **유리보정**: 타입1이 자신 타입이면, 주사위 2개 → 큰 값 사용
  - **불리보정**: 원거리(>3) 스킬 사용 중 근접 상태이상 적 있음 → 주사위 2개 → 작은 값 사용

## 데미지 계산

- (기술 상성) × (pow ÷ 100) × (max(내 공격 - 상대 방어, 0) + 16 + 1d4)
- **치명타**: 1d4 → 4 고정, 최종 데미지 × 2

# 🎯 볼 시스템

## 포획 판정

- 포획 요구치 = 20 × (피격자 현재 HP ÷ 피격자 최대 HP)
- 포획 성공 시 HP 최대로 회복

## 볼 종류

- **캔버스볼**: 상대 색 그대로
- **컬러볼**: RGB 각 성분 평균
- **라이트볼**: RGB 각 성분의 **밝기 합산 후 보정** (빛 혼합)
- **팔레트볼**: RGB의 **중간값** 혼합

# 🛡️ 대응 시스템

- 어떤 색깔말 주변(거리 3 이내)에 적이 있었는데  
  → 그 적이 거리 3 밖으로 벗어나면 **즉시 대응**
- 대응: **턴과 사거리 무관**하게 (타입1, 노말)의 스킬 자동 시전
